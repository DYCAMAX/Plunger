# Rabbids Mod Framework
![image alt](https://github.com/DYCAMAX/Rabbids-Mod-Framework/blob/1fa272abc8d884e950fd5b63c642296d5e16ed64/Rabbids%20Mod%20Framework%20Logo.png)
Rabbids Mod Framework is a tool that allows you to create a mod on Rayman Raving Rabbids (Wii) and soon all other Rabbids games officially available on Wii.
## Install Guide
Requirements:
- [Dolphin](https://dolphin-emu.org/?nocr=true)
- [Rayman Raving Rabbids](https://en.wikipedia.org/wiki/Rayman_Raving_Rabbids) Wii ISO Vanilla (Obtained legally, no ISO will be given)
## 
First, Vous devez vous meunir d'une rom de Rayman Raving Rabbids version Wii (legalement please) et Dolphin. 
Second, Ajoutez le jeu sur Dolphin et allez dans les propriété du jeu et dans filesystem
